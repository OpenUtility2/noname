What is MCTools?

MCTools is a collection of browser-based utilities for Minecraft server owners and developers. The project is maintained as part of OpenUtility and is designed around direct, useful workflows instead of unnecessary account setup.

✦The goal is simple: open a tool, do the job, copy or download the result, and get back to your server.

Built around a few principles

⚡

Useful first

The site focuses on practical Minecraft server tasks and keeps the interface centered on the action.

🧩

Small tools

Each utility has a focused job, making it easier to understand what goes in and what comes out.

🔒

Browser-first

Core tools are designed to work in the browser and do not require an account.

📚

Documented

Guides and references sit alongside the tools so you can understand the workflow instead of guessing.

Independent project

MCTools is not an official Minecraft service and is not affiliated with, endorsed by, or sponsored by Mojang or Microsoft.

The project is designed around vanilla HTML, CSS and JavaScript with an open-source workflow.

↗Want to explore the project? Visit OpenUtility on GitHub or use the Command Center to try the working tools.
