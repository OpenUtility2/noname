Data processing

MCTools is designed so ordinary tool inputs can be processed in the browser. This browser-first approach is intended to keep the core utility workflow simple.

ⓘSome features can require a network request. When a feature needs one, the page should explain that requirement rather than implying that all processing happens locally.

No account required

MCTools does not require an account for the core browser tools. You can use the utilities without creating a profile or signing in.

Some browser features may store local preferences or recent-tool information on your device. These are browser-side features rather than a requirement for an MCTools account.

Third-party resources

The current site may load third-party resources such as fonts or other libraries. Those requests are handled by the relevant third-party service, and their own policies govern them.

For example, the site currently uses Google Fonts resources for its typography.

Using the tools

Do not enter information into a tool that you are not comfortable processing in a browser or sending to a network service when that tool explicitly requires a network request. Check the individual tool's behavior and guidance before using sensitive information.
