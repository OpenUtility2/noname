How to edit server.properties

A practical guide to the most common Minecraft server.properties workflow.

Overview

A practical guide to the most common Minecraft server.properties workflow. This guide is intentionally focused on the workflow rather than assuming a particular hosting provider.

Before you change anything

  • Keep a backup of the current configuration.
  • Change one group of settings at a time when troubleshooting.
  • Restart the server when the setting requires a restart.
  • Check the server console/logs after changes.

Use MCTools

Use the relevant MCTools utility to prepare or inspect the data, then verify the result in your server environment.
