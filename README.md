**​MCTools** is ​a modern, open-source suite of web utilities for Minecraft server owners and developers. Built by OpenUtility using vanilla HTML, CSS, and JavaScript — no frameworks, no build step, no external server required.

**Features**
> Minecraft Purple & Dark-Blue Theme — Retro pixel typography with crisp dark-mode UI elements

> 100% Free & Open Source — No account required; live tools run directly in your browser
> Fully Responsive — Seamless layout across mobile, tablet and desktop screens
> Privacy Focused — File editing and generation happen locally where practical

**Live Tools**
> MOTD Generator (`motd.html`) — Create and live-preview Minecraft server MOTDs with color formatting.
> Server Icon Converter (`server-icon-converter.html`) — Resize and convert images into Minecraft's 64×64 server-icon.png format.
> Server Properties Editor (`server-properties.html`) — Upload, edit, validate, and download server.properties files.
> Java Arguments Generator (`java-arguments.html`) — Generate Java startup arguments based on server RAM, software, Java version, and performance options.
> Server Status Checker (`mc-checker.html`) — Check live Java/Bedrock server status, MOTD, version, players, and latency.

**Technologies Used**
HTML5 — Semantic, clean document structure
CSS3 — Custom CSS variables, pixel art styling, and Flexbox/Grid layouts
JavaScript (ES6+) — Pure Vanilla JS (zero external runtime dependencies)
Font Awesome 6 — Icons
Google Fonts — Press Start 2P, VT323, and Inter
